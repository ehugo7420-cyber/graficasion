# Graficación — dibujos con p5.js

Sitio web con HTML, CSS y JavaScript que reúne cinco dibujos de Khan Academy adaptados a p5.js
(Rana, Dientes de conejo, ¿Qué hay de cena?, Día nevado soleado y Muñeco de nieve)
y dos páginas teóricas: la etiqueta `<canvas>` y los fundamentos de p5.js.

## Estructura

- `index.html`, `canvas.html`, `p5.html`: portada y teoría
- `proyectos/`: una página por dibujo
- `js/`: el código de cada dibujo, más `main.js` (menú y visor de código)
- `css/styles.css`: estilos
