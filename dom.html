El DOM: Document Object Model

El DOM es la forma en que el navegador representa tu página para que JavaScript pueda leerla y modificarla mientras está abierta.

Qué es

Cuando el navegador abre un archivo HTML, no lo muestra como texto: lo lee y construye con él un árbol de objetos. Cada etiqueta (<body>, <h1>, <canvas>…) se convierte en un objeto al que se le llama nodo, y los nodos quedan conectados como en un árbol genealógico: padres, hijos y hermanos. A ese árbol se le llama DOM (Document Object Model, "modelo de objetos del documento").

Una forma de pensarlo: el HTML es el plano escrito de una casa, y el DOM es la casa ya construida. JavaScript no cambia el plano, cambia la casa: puede pintar una pared, agregar una puerta o quitar una ventana, y el navegador actualiza lo que ves sin recargar la página.

Un ejemplo de árbol

<body>
  <h1 id="titulo">Hola</h1>
  <p class="texto">Un párrafo</p>
</body>

Ese HTML se convierte en este árbol:

document
└── html
    ├── head
    │   └── title
    └── body
        ├── h1  (id="titulo")  →  texto: "Hola"
        └── p   (class="texto") →  texto: "Un párrafo"

El objeto document es la puerta de entrada: desde él se llega a todo lo demás.

Tipos de nodos

NodoQué representa
ElementoUna etiqueta HTML, como <p> o <canvas>.
TextoEl texto que está dentro de un elemento.
AtributoLos datos de una etiqueta, como id, class, src o width.
ComentarioLos comentarios <!-- --> del HTML.

Seleccionar elementos

Antes de cambiar algo hay que encontrarlo en el árbol:

MétodoQué devuelve
document.getElementById('titulo')El elemento con ese id.
document.querySelector('.texto')El primer elemento que coincide con un selector de CSS.
document.querySelectorAll('p')Todos los elementos que coinciden, en una lista.
document.getElementsByClassName('texto')Todos los elementos con esa clase.

En tu práctica de clase ya usaste el DOM sin darte cuenta: document.getElementById("myCanvas") busca en el árbol la etiqueta <canvas> para poder dibujar en ella.

Modificar elementos

Propiedad o métodoPara qué sirve
elemento.textContent = 'Nuevo texto'Cambiar el texto de un elemento. Es la opción más segura.
elemento.innerHTML = '<b>Hola</b>'Cambiar el contenido, interpretando etiquetas HTML. Se debe evitar con texto escrito por usuarios.
elemento.style.color = 'red'Cambiar estilos CSS directamente.
elemento.classList.add('clase'), .remove(), .toggle()Agregar, quitar o alternar clases de CSS.
elemento.setAttribute('width', 400)Cambiar un atributo.

Crear y eliminar elementos

El DOM no solo cambia lo que ya existe: también se pueden crear elementos nuevos desde JavaScript y agregarlos al árbol.

const item = document.createElement('li');   // 1. crear
item.textContent = 'Nuevo elemento';         // 2. darle contenido
lista.append(item);                          // 3. agregarlo al árbol
item.remove();                               // quitarlo

    Eventos

    Un evento es algo que ocurre en la página: un clic, mover el mouse, escribir en un campo. Con addEventListener le dices al navegador qué función ejecutar cuando pase:

    boton.addEventListener('click', () => {
  titulo.textContent = '¡Hiciste clic!';
});

    Los eventos más usados son click, pointermove (mover el mouse o el dedo), keydown (tecla presionada) e input (cambio en un campo de texto).

    El DOM y el canvas

    El elemento <canvas> es parte del DOM: es un nodo más del árbol, y se puede seleccionar, cambiar de tamaño o acomodar con CSS. Pero lo que dibujas dentro del canvas no está en el DOM. Son solo píxeles. La rana o el muñeco de nieve no son elementos que puedas seleccionar con getElementById; el navegador solo ve un rectángulo con una imagen adentro.

    Por eso un botón o un menú se hacen con elementos del DOM, y los dibujos animados con canvas. Muchas páginas combinan los dos.

    El DOM y p5.js

    p5.js trabaja con el DOM de dos formas. La primera: el lienzo que crea con createCanvas() es un <canvas> normal, y .parent('id') lo coloca dentro de un elemento de la página. Así se colocan los dibujos de este sitio dentro de <div id="lienzo">.

    La segunda: p5.js puede crear controles del DOM, como botones, deslizadores y campos de texto, con createButton(), createSlider() y createInput().

    deslizador = createSlider(10, 150, 60);   // mínimo, máximo, valor inicial
boton = createButton('Cambiar color');
boton.mousePressed(() => { /* ... */ });
// y en draw(): deslizador.value()

    Dónde se usa el DOM en este sitio

    • El menú del celular: el botón "Menú" agrega o quita la clase abierto con classList.toggle().
    • El botón "Ver código": carga el archivo del dibujo, escribe su texto con textContent y muestra u oculta el bloque con el atributo hidden.
    • El plano de la portada: busca su canvas con getElementById y escucha el evento pointermove.
    • Las animaciones: en las páginas del sol, las nubes y la estrella, el botón "Reiniciar" y la casilla "Repetir automáticamente" son elementos del DOM que controlan el dibujo con eventos.
    • Los dibujos con p5.js: usan .parent('lienzo') para colocar el canvas dentro de la página.

    Para ver el árbol del DOM de cada página de este sitio, dibujado con cajas y líneas, abre el Inspector del DOM.
