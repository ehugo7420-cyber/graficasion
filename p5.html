Fundamentos de p5.js

p5.js es una librería de JavaScript para dibujar y animar con pocas líneas de código. Es la que se usó para hacer los cinco dibujos de este sitio.

Qué es

p5.js es una librería de código abierto pensada para la programación creativa. Está inspirada en Processing, un lenguaje creado para enseñar programación a artistas y diseñadores, y lleva esa misma idea a la web. Por debajo usa el canvas con contexto 2D (y el contexto WebGL cuando se pide el modo WEBGL), pero oculta los detalles para que dibujar sea directo.

Cómo se agrega a una página

<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.4/p5.min.js"></script>
<script src="js/sketch.js"></script>

El primer script carga la librería y el segundo es tu dibujo. El orden importa: p5.js debe cargarse antes que tu código.

La estructura: setup() y draw()

Todo programa de p5.js gira alrededor de dos funciones que la librería llama sola:

  • setup() se ejecuta una vez al empezar. Aquí se crea el lienzo con createCanvas(ancho, alto).
  • draw() se ejecuta una y otra vez, unas 60 veces por segundo. Aquí van el dibujo y la animación.
function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(220);
  fill(255, 0, 0);
  ellipse(mouseX, mouseY, 50, 50);
}

p5.js dibuja como si pintaras con capas: lo que se dibuja después queda encima. Por eso en el muñeco de nieve el sombrero se dibuja al final. Además, fill() y stroke() se quedan activos hasta que los cambies.

Color

Por defecto los colores son RGB (rojo, verde, azul, de 0 a 255). fill(255, 0, 0) es rojo y fill(128) es gris. Con colorMode(HSB) se pueden describir por matiz, saturación y brillo, ideal para hacer cambios de color suaves, como en la demo. lerpColor() calcula un color intermedio entre dos; sirve, por ejemplo, para hacer degradados de cielo.

Variables del sistema

p5.js crea variables que siempre están actualizadas:

  • width y height: tamaño del lienzo.
  • mouseX y mouseY: posición del mouse; pmouseX y pmouseY: posición en el cuadro anterior.
  • mouseIsPressed: true mientras se mantiene un botón del mouse.
  • frameCount: cuántos cuadros se han dibujado. Sirve para animar con sin(frameCount * 0.05).
  • key: la última tecla presionada.

Eventos

Además de setup() y draw(), p5.js busca funciones con nombres especiales y las ejecuta cuando ocurre algo: mousePressed(), mouseReleased(), mouseMoved(), keyPressed(). Los dibujos de este sitio no las necesitan, pero son la base de cualquier programa interactivo.

Transformaciones

translate(x, y) mueve el origen, rotate(ángulo) gira el sistema de coordenadas y scale() lo agranda. Como afectan todo lo que se dibuja después, se encierran entre push() y pop(), que guardan y restauran el estado. Por ejemplo, para girar una oreja sobre su base:

push();
translate(150, 160);   // mover el origen a la base de la oreja
rotate(angulo);        // girar
ellipse(0, -75, 62, 175);
pop();                 // volver a como estaba

Los ángulos se miden en radianes. Con angleMode(DEGREES) puedes usar grados.

Modo global y modo instancia

En modo global, el que usamos, las funciones como ellipse() están disponibles directamente. En modo instancia todo se guarda dentro de un objeto, lo que evita choques de nombres si hay varios dibujos en la misma página:

const miDibujo = (p) => {
  p.setup = () => { p.createCanvas(400, 400); };
  p.draw  = () => { p.background(220); p.ellipse(p.mouseX, p.mouseY, 50); };
};
new p5(miDibujo, 'contenedor');
