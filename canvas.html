La etiqueta <canvas> y el contexto 2D

El <canvas> es el lienzo de la web: un rectángulo de píxeles en el que dibujas con JavaScript. p5.js, y los dibujos de este sitio, están construidos encima de él.

Qué es

<canvas> es un elemento de HTML5 que reserva un área rectangular de la página. Por sí solo no muestra nada: es una superficie en blanco y transparente. Todo lo que aparece en ella se dibuja con código JavaScript.

Es un lienzo de mapa de bits (raster): guarda una cuadrícula de píxeles, no una lista de objetos. Si dibujas un círculo y después quieres moverlo, no puedes "agarrarlo": tienes que borrar la zona y dibujarlo de nuevo. Por eso las animaciones se hacen redibujando todo en cada cuadro.

El texto que pongas entre las etiquetas de apertura y cierre solo se muestra en navegadores que no soportan canvas.

Tamaño del canvas

El tamaño se define con los atributos width y height. Si no los pones, el canvas mide 300 × 150 píxeles. Cambiar el tamaño solo con CSS no cambia la cantidad de píxeles: estira o encoge la imagen y el dibujo se ve borroso o deformado. Por eso en la práctica de clase se asignó canvas.width = 500 desde JavaScript.

Cómo se usa: tres pasos

<canvas id="lienzo" width="400" height="300">
  Tu navegador no soporta canvas.
</canvas>

<script>
  // 1. Obtener el elemento
  const lienzo = document.getElementById('lienzo');
  // 2. Pedir el contexto de renderizado
  const ctx = lienzo.getContext('2d');
  // 3. Dibujar
  ctx.fillStyle = '#27c1e0';
  ctx.fillRect(20, 20, 150, 100);
</script>

Contextos de renderizado

Un contexto de renderizado es el objeto que trae las herramientas para dibujar. Se obtiene con canvas.getContext(tipo), y el tipo decide cómo se dibuja.

TipoPara qué sirve
'2d'Gráficos en dos dimensiones: formas, líneas, texto, imágenes. Devuelve un CanvasRenderingContext2D. Es el que usamos aquí.
'webgl' y 'webgl2'Gráficos 3D acelerados por la tarjeta gráfica (GPU). Son más potentes y más complejos. p5.js los usa en su modo WEBGL.
'bitmaprenderer'Muestra de forma eficiente una imagen ya creada (ImageBitmap) sin dibujar sobre ella.
'webgpu'La interfaz más moderna para usar la GPU. Su soporte todavía depende del navegador.

Un canvas solo puede tener un tipo de contexto. Si ya pediste '2d' y luego pides 'webgl' sobre el mismo canvas, el navegador devuelve null.

Sistema de coordenadas

El origen (0, 0) está en la esquina superior izquierda. La x crece hacia la derecha y la y crece hacia abajo, al revés de la gráfica de matemáticas. Puedes comprobarlo en el plano de la página de inicio.

El contexto 2D: lo que más se usa

TemaMétodos y propiedades
RectángulosfillRect(x, y, ancho, alto), strokeRect(), clearRect()
TrazadosbeginPath(), moveTo(), lineTo(), arc(x, y, radio, inicio, fin), closePath(), luego fill() o stroke()
EstilosfillStyle, strokeStyle, lineWidth, globalAlpha
Textofont, fillText(texto, x, y), measureText()
Transformacionestranslate(), rotate(), scale(), save() y restore()
ImágenesdrawImage(imagen, x, y)

Los ángulos de arc() y rotate() se miden en radianes: una vuelta completa es Math.PI * 2.

Animación

Una animación es dibujar muchas imágenes seguidas. En cada cuadro se borra el canvas con clearRect(), se actualizan las posiciones y se dibuja de nuevo. requestAnimationFrame() le pide al navegador que ejecute tu función justo antes de pintar el siguiente cuadro, normalmente 60 veces por segundo.

function cuadro() {
  ctx.clearRect(0, 0, c.width, c.height);  // borrar
  x += vx;                                  // actualizar
  ctx.arc(x, y, r, 0, Math.PI * 2);         // dibujar
  requestAnimationFrame(cuadro);            // repetir
}
cuadro();

La pelota rebota porque se invierte su velocidad al llegar a un borde.

Práctica de clase: texto arcoíris

Dibujar el mismo texto siete veces, cada una con un color distinto y desplazada 3 píxeles, crea el efecto de sombra arcoíris. Usa un ciclo, un arreglo de colores y fillText().

Del canvas a p5.js

Todo lo anterior funciona, pero requiere mucho código para cosas simples. p5.js envuelve el contexto 2D con funciones más cortas. Lo que aquí es ctx.fillRect(20, 20, 150, 100), allá es rect(20, 20, 150, 100). Sigue en la página de p5.js.
